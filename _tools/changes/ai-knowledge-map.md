# The AI Knowledge Map, version 3.0 (November 2026)

- Corrected the MCP entry to the current specification, revision 2026-07-28: the protocol is now stateless, the opening handshake and sessions are gone, Tasks are an extension, and Roots, Sampling and Logging are deprecated. It links to the specification and is marked "as of November 2026".
- Corrected the A2A entry to version 1.0 (March 2026): the Agent Card is published at `/.well-known/agent-card.json`, the task states now include input-required and auth-required, and the project is recorded as part of the Agentic AI Foundation since August 2026. It links to the specification and is marked "as of November 2026".
- Corrected who founded the Agentic AI Foundation (Anthropic, Block and OpenAI), the order in which a language model is trained, and the claim that all of today's AI is "narrow", which is an opinion and is now presented as one.
- Added a reading order: a numbered "start here" path of eleven steps, shown above the map and on every circle.
- Redrew the map so that it shows how the ideas relate: AI, machine learning, deep learning, generative AI and LLMs are nested boxes, and every arrow carries a label such as "is built on" or "supplies facts to".
- Added a list view with the same content as the map. It works on a phone, with a screen reader, in print and with JavaScript switched off.
- Made moving and zooming the map real. The old page promised it and did not do it. It now works with a mouse, with two fingers on a touch screen, and with buttons and keys, and there is a reset button.
- Made the whole page usable from the keyboard, added headings, and let the page scroll so that the site header and footer are always reachable.
- Removed product and version names that had gone out of date (retired agent products, old model version numbers, a superseded agent framework) and replaced them with descriptions that will last, or with names checked in November 2026.
- Removed figures that had no source (a rumoured parameter count, a productivity claim, a language count). Every remaining figure now has a link to its source and a date.
- Added a short "check yourself" section and links to the three related guides: Agentic AI Runtime Architecture, Securing AI Systems and Agents, and Data Intelligence Layer.
- Rewrote the text in British English and removed all long dashes.
