# Agentic AI Runtime Architecture, version 3.1 (November 2026)

- Corrected the security guidance. The page used to say that input validation prevents prompt injection. It does not: prompt injection cannot be reliably prevented, only made less likely and contained. The Guardrails panel now starts from that assumption, names indirect injection (through tool results, retrieved documents, web pages, emails, saved memory and other agents), and says for each control what it does not stop.
- Rewrote the Identity panel around how agent authorisation is actually done: an identity for every agent and tool call, short-lived scoped tokens, explicit delegation instead of silently inheriting the user's authority, checks at the tool boundary, and an evidence record of who acted, on whose behalf, with which inputs and under which policy. Removed "ARIA (Agent Relationship Identity)", which I could not find as a standard.
- Updated the protocol panel against each project's own site, with a "status as of November 2026" line and a link for each: MCP (revision 2026-07-28 and its OAuth-based authorisation model), A2A (version 1.0, now with the Agentic AI Foundation), ANP, and Agora. ACP is marked as merged into A2A in August 2025.
- Corrected AGENTS.md: it is a file of instructions for coding agents working in a repository, not a description of an agent's capabilities.
- Fixed four code samples that would not have run: the working-memory compression loop never ended, the function executor had no real idempotency and would have dropped a legitimate second email, the human-approval gate was called with the wrong arguments, and the Temporal workflow used argument names that do not exist. Five samples are now complete Python that was run for this page; every other sample is labelled as a sketch.
- Corrected "exactly-once" to "at least once" for durable workflow steps, which is why they need idempotency keys, with a link to the Temporal documentation.
- Replaced the 2023-style text ReAct prompt with the native tool-calling loop that is current practice, and added the caveat that a model's own confidence or 1 to 10 score is not calibrated and should not open or close a gate.
- Removed or sourced unsupported claims: cost as "the #1 reason" projects are cancelled now cites Gartner (June 2025), and "dramatically reduces token costs" and "produces higher-quality decisions" are gone. Stale product names and model versions were updated or made generic.
- Added a "Further reading" block: the OWASP Top 10 for LLM Applications, the OWASP Top 10 for Agentic Applications for 2026, MITRE ATLAS, and this site's guide to securing AI systems and agents.
- Every card and panel now works from the keyboard and on a phone, and the whole page, including all 37 detail panels, is readable with JavaScript turned off. The smallest text is larger and has better contrast.
- Removed the "click analytics" widget, which only counted your own clicks and looked like tracking. Added the shared site header, the licence (CC BY-NC-SA 4.0) and a correction link.
- The version shown on the page was wrong (it said 1.0, March 2026). It is now 3.1, November 2026, in the header and the footer. The memory layer no longer lists a "procedural memory" that the page never described, and the seven-layer numbering is now stated to be my own, not an industry standard.
